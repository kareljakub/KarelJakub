# Karel Jakub

I build systems by removing the parts that exist to make them feel official.

The result is usually smaller and faster than the version that starts with a team and a process. AI is useful only as a way to test a clear idea quickly. The idea still has to be good. The limits still have to be hard.

Most of the work is agent systems with explicit roles and hard checks. The goal is to move from idea to working tool without the layers that normally sit in between. The same approach applies to practical automation — Linux, Home Assistant, and the kind of smart home setups that actually reduce work instead of adding another dashboard.

The consistent filter is fewer moving parts, fewer people in the loop, and fewer rules that exist only because nobody questioned them.
